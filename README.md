## 🖥️ What is DanVerse?

**DanVerse is a desktop inside your browser.**  
It can also be installed as an app on desktop and mobile.

DanVerse is a personal space where I bring together tools, creations, games, experiments, and projects into a single interactive environment.

Instead of navigating a traditional website, you interact with a web-based desktop. You can open applications, move and resize windows, customize the interface, and explore everything from the same place.

## ✨ Features

- 🖥️ **Desktop interface** — A familiar desktop experience running entirely in the browser.
- 🪟 **Window management** — Open, move, resize, minimize and interact with multiple windows.
- 🎨 **Customizable desktop** — Change backgrounds, colors, themes and other visual settings.
- 🌈 **Personal themes** — Configure the desktop to match your own style.
- 🧰 **Tools & utilities** — A collection of useful tools available directly from the desktop.
- 🎮 **Games & experiments** — Games and interactive projects gathered in one place.
- 🎨 **Creative projects** — 3D work, experiments and other creations.
- 📱 **Responsive** — Designed to work on both desktop and mobile.
- 📦 **Installable** — Available as a Progressive Web App.
- ⚡ **Fast & lightweight** — Built with performance and low resource usage in mind.
- 📴 **Offline capable** — Core features can continue working without a constant internet connection.
- 🔒 **Local-first** — Personal settings and desktop configuration are stored locally in your browser.

## 🎨 Make It Yours

DanVerse is designed to be customizable rather than looking exactly the same for everyone.

You can change the desktop background, colors, themes and other preferences to create an environment that feels like your own.

**Your desktop, your way.**

## 🔒 Privacy First

**In DanVerse, privacy isn't an extra feature. It's part of how the desktop works.**

DanVerse follows a local-first approach. Your configuration, window positions and preferences are stored locally in your browser using **Local Storage**.

No account is required to customize the desktop, and the personal configuration of your environment does not need to be stored on an external server.

**Your desktop. Your settings. Your data.**

## 🧩 The Experience

DanVerse takes inspiration from classic desktop operating systems, but runs entirely inside the browser.

Multiple applications can coexist within the same desktop, making it possible to move between tools, games, projects and experiments without leaving the environment.

The desktop itself becomes the way you navigate DanVerse.

## 📱 Progressive Web App

DanVerse is a **Progressive Web App (PWA)**.

On supported devices, it can be installed and launched like a regular application without going through a traditional installation process.

The project is built around:

- ⚡ Fast loading
- 📴 Offline capabilities
- 📦 Installability
- 📱 Responsive interfaces
- 🌐 Browser-native technologies

## 🛠️ Built With

DanVerse is built using standard web technologies with a focus on keeping the experience lightweight and responsive.

- HTML
- CSS
- JavaScript
- PWA
- Web APIs
- Local Storage

The project is also a place for me to experiment with interfaces, interactions, games, tools and new ideas.

## 🎯 Why DanVerse?

DanVerse started as a personal project.

I'm a developer and 3D designer, and I wanted a place where I could bring together the things I build and experiment with without turning them into a collection of unrelated pages.

The result is somewhere between a portfolio, toolbox, game collection, creative playground and web desktop.

It's still evolving, and that's part of the point.

## 🎨 More Than a Portfolio

DanVerse isn't just a showcase for my projects.

It's an environment where projects can **live and interact**.

Tools, games, experiments, 3D creations and other ideas can coexist within the same desktop, while the interface itself can be customized by the person using it.
